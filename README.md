# VOLT — магазин HOCO J89A

## Що вже підготовлено
- Адаптивний односторінковий магазин українською.
- 4 фотографії товару, завантажені користувачем, з перемиканням галереї.
- Ціна 2 290 грн, контакти телефону й Telegram.
- Форма замовлення з ім’ям, телефоном, доставкою, кольором і кількістю.
- Netlify Functions для приймання замовлень та адміністративного перегляду/зміни статусів.
- SQL-схема таблиці Supabase.

## Що ще НЕ підключено
Сайт не опублікований і замовлення поки що не можуть реально зберігатися/надсилатися: для цього потрібні ваші акаунти GitHub, Netlify та Supabase і налаштування секретів. Telegram-бот також ще не створений.

## Публікація
1. У GitHub створіть порожній репозиторій, наприклад `volt-store` (без README/License).
2. Розпакуйте ZIP на комп’ютері. Завантажте в репозиторій ВСІ файли й папки з архіву (папки `public`, `netlify`, файли `netlify.toml`, `supabase-schema.sql`, `README.md`). На телефоні це незручно; краще виконати з комп’ютера.
3. У Supabase створіть проєкт. Відкрийте SQL Editor і виконайте вміст `supabase-schema.sql`.
4. У Netlify оберіть Add new site → Import an existing project → GitHub → репозиторій `volt-store`. Build command залиште порожнім, Publish directory — `public`; `netlify.toml` задає Functions.
5. У Netlify → Site configuration → Environment variables додайте:
   - `SUPABASE_URL` — Project URL із Supabase.
   - `SUPABASE_SERVICE_ROLE_KEY` — service_role secret із Supabase (НІКОЛИ не публікувати й не надсилати в чат).
   - `ADMIN_PASSWORD` — новий довгий унікальний пароль для `/admin`.
   - `TELEGRAM_BOT_TOKEN` і `TELEGRAM_CHAT_ID` — після створення Telegram-бота.
6. Запустіть redeploy. Перевірте тестове замовлення, появу запису в Supabase, Telegram і адмінку `/admin`. Не приймайте реальні замовлення, доки тест не пройшов.

## Telegram
Створіть бота через `@BotFather`, натисніть Start у новому боті зі свого Telegram-акаунта, отримайте chat ID (можна через `@userinfobot` або API getUpdates) і внесіть обидва значення в Netlify Environment Variables. Не публікуйте токен бота.

## Важливо перед запуском
- Перевірте, що заявлені характеристики й комплектація відповідають фактичному товару.
- Додайте юридичні дані продавця, політику конфіденційності, умови доставки/оплати/повернення.
- Адмінка — базовий MVP на парольному секреті; для серйозного використання варто перейти на повноцінну авторизацію й додати захист від спаму.
- Контактний телефон і Telegram показуються публічно на сайті.
